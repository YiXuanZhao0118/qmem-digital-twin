# The Alembic migration chain

> Startup / upgrade steps are in [runbook.md](runbook.md); known problems in [known-issues.md](known-issues.md).

- **Head:** `0121_mechanical_kind`; **root:** `0001_initial_schema`.
- One linear chain — no gaps, no branches, no duplicate revision ids. `env.py` takes its autogenerate target metadata from `from app.models import Base`.
- Revision ids are deliberately abbreviated to stay under the **VARCHAR(32)** limit (0091 once broke it and stranded the DB at 0090; that is healed now — the newest, `0118_asset_device_id`, is 20 characters).
- Key migrations: 0036–0039 multiphysics sidecar tables; 0082–0084 v3 asset physics columns; 0086 kinds registry; 0093 flatten frame anchors (removes the body frame); 0094/0095 strip component physics; 0096 drop PE intrinsic/state; 0097 repair dynamic sources; **0106 drop assets_3d.faces + transitions (the v2 face path retires → anchors)**; 0107 rename anchor_template; 0108 rf_switch filepath; **0109 drop the circuits table + purge simulation runs of the removed modules (Optics/Electronics/EM)**; 0110 unclassified kind; 0111 asset kind NOT NULL; 0112 locked flag; **0113 drop objects.param_overrides + add assets_3d.tunable_params (per-instance tunability is now marked on the Asset, values travel in dynamic_sources)**; 0114–0117 connector kind/asset/component (see [kinds.md](kinds.md)); **0118 add assets_3d.device_id (pointer into the device registry; see the device section of [kinds.md](kinds.md))**; 0119 seed the `primitive://text_annotation` asset (catalog_id `text_annotation_label`, kind `unclassified`; the binding leaf of a text annotation, see [rendering.md](rendering.md)); 0120 AOM `crystalLengthMm` = 22.4; **0121 add the `mechanical` kind (passive mount/post/holder hardware, `op_set_name='none'`, `domains=['mechanical']`; see [kinds.md](kinds.md))**.
- ⚠️ **Never delete** an applied migration — including the ones whose names look experimental (`v2`/`v3`/`baseline`/`cutover`, e.g. 0027–0034, 0082–0084). Deleting one breaks the chain, breaks `alembic upgrade head`, and strands the DB on the previous revision. The names look like experiments; the migrations are the real history.
